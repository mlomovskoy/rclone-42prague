1. Who this policy covers

This policy describes how the application rclone-42prague ("the app") handles information. The app is a personal, non-commercial configuration of the open-source program rclone, operated by Maxim Lomovskoy as an individual. The app is used only by its author, on their own devices, with their own Google account.

2. What the app accesses

The app requests one Google API scope:

https://www.googleapis.com/auth/drive.file

This scope gives per-file access: the app can only read, create and modify files and folders in Google Drive that the app itself created, or that the user explicitly selected for it. The app has no access to any other content in the user's Google Drive, and does not request access to Gmail, Contacts, Calendar, Photos, or any other Google service.

3. What the app does with data

  • File contents are transferred directly between the user's own device and Google's servers.
  • The app does not send file contents, file names, or metadata to the developer or to any third party.
  • There is no server, database, analytics service, or hosted backend operated by the developer. This website is a set of static pages and does not receive any data from the app.
  • No advertising, profiling, tracking, or machine-learning training is performed on any data.
  • No data is sold, rented, or shared. It is never transferred to anyone else.

4. Credentials and tokens

When the user signs in with Google, Google issues an OAuth access token and refresh token. These are stored only in the rclone configuration file on the user's own computer (typically ~/.config/rclone/rclone.conf). The developer never receives or stores them. Their security depends on the security of the user's own device and account.

5. Data retention and deletion

The app stores no data of its own beyond the local rclone configuration file. Access can be revoked at any time from the Google Account permissions page at myaccount.google.com/permissions. Deleting the local rclone configuration file removes the stored tokens from the device. Files in Google Drive are managed by the user directly through Google Drive.

6. Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Children

The app is not directed at children and is not intended for use by anyone under 13.

8. Changes to this policy

If this policy changes, the updated version will be published on this page with a new "last updated" date.
